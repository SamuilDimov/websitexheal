# xHeal Landing Page Structure

Last updated: 2026-03-06
Use case: campaign pages, feature pages, condition pages, quiz landing pages

## 1) Page Goal Framework
Define before writing:
- Audience: one primary segment
- Offer: one conversion action
- Proof: one strongest credibility set
- Friction: one main objection to resolve

## 2) High-Converting Section Order
1. Hero
2. Problem Agitation
3. Mechanism (How xHeal Works)
4. Outcomes / Benefits
5. Proof (stats, standards, testimonials)
6. Feature Deep-Dive
7. Objection Handling (FAQ)
8. Final CTA
9. Compliance footer note

## 3) Hero Blueprint
Headline:
- Outcome + prevention or continuity

Subheadline:
- What xHeal connects + what action it enables

Primary CTA:
- Start care now (or campaign-specific equivalent)

Secondary CTA:
- See how it works / View sample report

Optional proof strip:
- 250+ parameters
- specialist-ready reports
- standards alignment

## 4) Messaging Pattern by Section
Problem section:
- Name real pain in user language
- Explain why current approach fails

Mechanism section:
- Inputs: labs + records + wearables + logs
- Process: cross-correlation over time
- Output: early signal + clear next step

Outcome section:
- Fewer reactive episodes
- Better appointment quality
- Higher confidence in daily decisions

## 5) Objection Handling Blocks
- "I already use other apps" -> "xHeal connects what you already track."
- "Will my doctor use this?" -> "Use specialist-ready reports built for appointments."
- "Is this replacing my doctor?" -> "No. xHeal supports care decisions and follow-through."
- "Is my data safe?" -> "User-controlled sharing and compliance-forward handling."

## 6) CTA Placement Rules
- Hero CTA above the fold
- CTA after mechanism section
- CTA after proof section
- Final CTA at page bottom

Rule:
- Same primary CTA wording repeated for consistency

## 7) Condition Page Variant (Template)
Hero: "Predict [condition]-related patterns earlier"
Problem: "[Condition] patterns are hard to see across fragmented tools"
Mechanism: "xHeal correlates your [condition-relevant data inputs]"
Proof: 2-3 condition-relevant testimonials
CTA: "Start care now"

## 8) Quiz LP Variant (Template)
Hero: "Why am I still feeling off?"
Subhead: "Take a 2-minute pattern quiz and get your result archetype."
Bullets:
- Understand likely missing context
- See your next best action
- Get personalized follow-up
CTA: "Take the pattern quiz"

## 9) Compliance and Trust Placement
- Near first CTA: support-not-replace statement
- Near FAQ: no diagnosis/treatment clarification
- Footer: informational-use disclaimer

## 10) Final Pre-Publish QA
- One audience and one offer only
- Headline expresses one clear outcome
- Mechanism is concrete (not vague AI claims)
- At least one approved proof block included
- FAQ resolves top 3 objections
- Compliance-safe wording present
- Mobile above-the-fold CTA visible without ambiguity
